# Company Website (Homepage Mockup)

This project is a **homepage mockup** for a financial services company.  
The goal is to establish the visual direction, layout structure, and branding style for the full website.

Only the **homepage** is currently implemented.

---

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion (scroll fade-in animations)

---

## Fonts

- Headings: **Roboto Serif**
- Body Text / Buttons: **DM Sans**

---

## Notes

This is not the final production build.  
Content, images, and sections can be refined or expanded in later stages.
